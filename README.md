# 星际突围 · 深空航线

基于上传的飞机大战改进的 HTML Canvas 游戏，保留原程序的 MIT 授权。单个 HTML 文件包含全部代码与绘图资源，无需依赖、密钥或联网加载素材。

## 运行

将 `index.html` 保存后用现代浏览器打开，或在本目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

## 敌机与刷新

| 类型 | 血量 / 击落所需命中 | 基础刷新权重 | 行为 |
| --- | --- | --- | --- |
| 普通机 | 3 | 80% | 小型紫红蝠翼，向下飞行，不发射子弹 |
| 高级机 | 10 | 18% | 紫色重装钳翼，较慢移动；每 2.2 秒左右各偏离正下方 30° 发射一发，弹速 150 像素/秒 |
| Boss 无畏舰 | 100 | 2% | 大型五炮旗舰，进场后固定在屏幕中上方；五向扇形弹幕与周期性快速扫射 |

每颗我方子弹造成 1 点伤害，每架敌机被击落计 1 次。敌机身上显示剩余血量，Boss 使用独立的顶部血条。

权重按每次刷新抽签计算。Boss 在开局 30 秒后才能出现，同场最多一架，两次出现至少间隔 60 秒；允许刷新后 45 秒内未抽中则保底出现。Boss 不满足条件时，改按普通 / 高级机相对权重刷新。Boss 在场时减少其他敌机刷新密度，给弹幕战留出操作空间。

Boss 常态每 0.75 秒发射五向子弹，方向为正下方的 −50°、−25°、0°、25°、50°，弹速 220 像素/秒。停稳后每 9 秒包含一次扫射：先预警蓄能 0.6 秒，再以每 0.09 秒一发、330 像素/秒的速度从 −70° 扫到 +70°，持续 2.2 秒。扫射期间替代常态扇形射击。

## 我方战机与操作

- 鼠标移动：飞机中心精确跟随鼠标，支持全画面横纵移动，无需按住鼠标；飞机不会越出画面。
- 手机：按住画面拖动；点击右下角超载按钮使用技能。
- 装甲血量：20 点。每颗敌弹扣 1 点，第 20 次命中死亡；受击闪光仅为视觉提示，没有吞掉伤害的无敌时间。
- **撞机立即死亡**，与剩余血量无关，开局也没有碰撞保护。
- 自动射击：每 80 毫秒一发，约每秒 12.5 发。
- **右键 / E / 右下角按钮开启超载**：持续 10 秒，同时发射三束平行子弹，每秒约 37.5 发；冷却 60 秒，从开启时开始计时（持续结束后还需等待 50 秒），不能重复开启延长效果。
- 空格、Esc 或右上角按钮：暂停 / 继续；切换到后台自动暂停。血量、敌弹、超载持续时间和冷却均随游戏暂停。
- 游戏结束：点击「再次出发」，按 R / Enter 或点击弹窗外背景重新开始；血量、弹幕、Boss 与技能计时全部重置。

最高击落数保存在浏览器本地；浏览器禁用存储时仍可正常游戏。

## 图形

我方是银灰尖翼截击机，带发光座舱和双离子推进器；普通敌机是紫红蝠翼，高级机是重装钳翼，Boss 是橙红反应堆与五门炮组成的宽幅无畏舰。各型战机均有不同轮廓与毁伤图形，由 Canvas 绘制并在初始化时缓存。

背景包含多层星空与星云、天王星及光环、海王星及风暴、带吸积盘的黑洞与远方星球。背景纹理在初始化和调整窗口时缓存，动画与战斗采用时间增量。

## 验证

当前云环境提供 Python Playwright 与 Chromium。启动网页服务后运行：

```bash
python3 tests/test_game.py
python3 tests/test_combat.py
```

前者检查鼠标 / 触屏、边界、窗口与高分屏、射速、单颗子弹不重复伤害、暂停和重开。后者检查三类敌机的命中阈值、刷新权重、玩家 20 次中弹与碰撞死亡、弹幕角度 / 射速、Boss 驻留与刷新限制、超载时长和冷却、右键及触屏技能操作。两者同时检查浏览器错误和外部请求；状态观察接口只注入测试浏览器的拦截响应，正式页面不暴露测试接口。
